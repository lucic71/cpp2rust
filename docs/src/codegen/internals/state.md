# Converter State

The visitors do not pass context down as arguments; they read it from member
variables of the converter. Fields that only hold for a subtree are set through
an RAII guard, declared in `converter.h` next to the field, that restores the
previous value on exit. The `static` fields survive from one `Converter`
instance to the next, because one process converts every translation unit of a
`--dir` build into a single output (see
[The Translation Pipeline](../pipeline.md)).

| Member                                                 | Description                                                                                                                                                                                                                                     |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rs_code_`                                             | The output string. `Buffer` swaps it for a scratch string so a visitor's output can be captured and post-processed before it is appended.                                                                                                       |
| `ctx_`                                                 | The `clang::ASTContext` of the current translation unit.                                                                                                                                                                                        |
| `sema_`                                                | The `clang::Sema` of the current unit, set by `SetSema`; used to instantiate template method definitions and implicit copy constructors on demand, and by the `emplace_back` [plugin](../expressions/plugins.md) to build the constructor call. |
| `keyword_unsafe_`, `keyword_mut_`, `keyword_const_fn_` | `"unsafe"`, `"mut"`, `"const"` in the unsafe model and empty strings in the refcount model, so shared code paths print the right qualifiers.                                                                                                    |
| `curr_expr_kind_`                                      | Stack of [`ExprKind`](../expressions/kinds.md) (`LValue`, `RValue`, `XValue`, `AddrOf`, `Object`, `Callee`, `Void`) saying how the expression being converted is used; pushed with `PushExprKind`.                                              |
| `computed_expr_type_`                                  | Whether the expression just printed is a fresh (owned) value or pointer, or names existing storage; overwritten by every visitor and read by `ConvertFresh*` to decide on a `.clone()` (see [Freshness](../expressions/kinds.md#freshness)).    |
| `curr_init_type_`                                      | Stack of the types being initialized, pushed by `PushInitType` around an initializer or assignment; a string literal reads it to pad a `char s[N]` initializer.                                                                                 |
| `autoref_mut_`                                         | Set by `PushExplicitAutoref` when a dereference is the base of an index, so `EmitDeref` prints `(&mut (*p))` / `(&(*p))` instead of `(*p)` (see [Dereference](../types/pointers.md#dereference)).                                               |
| `suppress_iterator_clone_`                             | Set by `PushSuppressIteratorClone` around a converting constructor of an iterator type and taken once by the copy-constructor conversion, so the iterator is not cloned twice (see [Iterators](../types/special-types.md#iterators)).           |
| `curr_function_`                                       | The function whose body is being converted; `return` takes its return type from it, and `mut` on locals is dropped inside virtual methods.                                                                                                      |
| `in_function_formals_`                                 | True while a parameter list is printed, so parameter types are not boxed (see [Functions](../declarations/functions.md)).                                                                                                                       |
| `in_const_initializer_`                                | True inside a global initializer in the unsafe model, which must be a constant expression (see [Global Variables](../declarations/globals.md)); set by `PushConstInitializer`.                                                                  |
| `curr_for_inc_`                                        | Stack of the increment expressions of the enclosing `for` loops, replayed before every `continue` (see [Control Flow](../statements/control-flow.md)).                                                                                          |
| `break_target_`                                        | Stack of `BreakTarget` saying whether a `break` leaves a loop, a `switch!` arm, or a fallthrough switch; pushed by `PushBreakTarget` (see [Switch](../statements/switch.md)).                                                                   |
| `hoisted_decls_`                                       | Locals hoisted out of a `goto_block!`, whose later declaration is printed as an assignment; scoped by `PushHoistedDecls` (see [Goto and Hoisting](../statements/goto.md)).                                                                      |
| `map_iter_decls_`                                      | Range-`for` variables over a `std::map`, which are the iterator itself and are not dereferenced on use; scoped by `ScopedMapIterDecl` (see [Iterators](../types/special-types.md#iterators)).                                                   |
| `decl_ids_` (static)                                   | IDs of the declarations outside the main file that have been emitted, so a header included by several units is emitted once (see [Translation Unit](../statements/translation-unit.md)).                                                        |
| `record_decls_` (static)                               | `RecordIndex`: record names marked referenced or defined; after the last unit `EmitOpaqueRecords` prints `pub struct Name;` for the referenced-only ones.                                                                                       |
| `abstract_structs_` (static)                           | IDs of the classes with pure virtual methods, emitted as traits, so pointers to them become `dyn` (see [Traits](../types/traits.md)).                                                                                                           |
| `inner_structs_` (static)                              | Nested record ID to its flattened Rust name (see [Naming](../types/naming.md)).                                                                                                                                                                 |
| `globals_` (static)                                    | Names of the emitted file-scope globals, so a global seen through several declarations is emitted once.                                                                                                                                         |
| `pending_deref_` (refcount)                            | A dereference whose consumer is not known yet, held as a pointer expression until an assignment, mapped method call, or increment consumes it (see [Pending Dereferences](../expressions/pending-deref.md)).                                    |
| `conversion_kind_` (refcount)                          | Stack of `ConversionKind` (`FullRefCount`, `Ptr`, `Unboxed`) telling `Convert(QualType)` how much of the refcount wrapping to print; pushed by `PushConversionKind` (see [Boxing](../types/boxing.md)).                                         |
